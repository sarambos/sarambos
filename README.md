## Hi, I'm Stephanie!

My experience includes building mobile and cloud-based applications and conducting graduate research in uncertainty-aware simultaneous machine translation. I enjoy solving technical problems, learning new technologies, and turning ideas into practical software.

A mobile expense-splitting application designed to simplify splitting shared expenses.

- Integrated DynamoDB for persistent expense and receipt history
- Implemented expense calculations, tipping, and split reports
- Developed collaboratively using Git and GitHub

#### Mobile Translator App

A mobile application for translating text between languages and listening to translated speech.

- Built with React Native, Expo, and TypeScript

- Implemented multilingual language selection and audio playback
- Designed reusable components and centralized API configuration
